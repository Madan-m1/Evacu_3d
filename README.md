# 🚨 Evacu3D – AI Emergency Evacuation Platform (Internship Project)

🚀 Real-time full-stack system designed to assist in emergency evacuation scenarios using multi-user synchronization and intelligent routing.

---

## ⚡ Key Features
- 🧭 Real-time evacuation tracking with multi-user synchronization  
- ⚡ WebSocket-based communication using Socket.io  
- 🔐 Secure authentication and role-based access control  
- 📊 Dynamic dashboard for monitoring evacuation flow  
- 🗺️ Integration-ready architecture for location-based services  
- 📱 Responsive UI for accessibility across devices  

---

## 🛠 Tech Stack
- **Frontend:** React.js, HTML, CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Real-Time:** Socket.io (WebSockets)  
- **Auth:** JWT
